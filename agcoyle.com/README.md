# A.G. Coyle Concrete website redesign

Static, responsive redesign based on the public content and project photography from `agcoyle.com`.

## Preview

Open `index.html` directly, or serve this folder locally:

```powershell
python -m http.server 8000 --directory agcoyle.com
```

Then visit `http://localhost:8000`.

## Notes

- The inquiry form uses the visitor's email client and sends to `alan@agcoyle.com`; no backend is required.
- Project images in `assets/images/` were sourced from the existing public A.G. Coyle gallery.
- Confirm the displayed street address and license details with the business before production deployment.
